# 专家目录

## 文献与证据

- **文献检索专家**：检索问题、关键词、数据库检索式、筛选、去重、引用核验、证据矩阵和文献导出。
- **论文精读专家**：重建研究问题、方法、公式、实验—结论证据链、结论边界、局限与可检验研究思路。
- **网络数据获取专家**：仅在数据被证明确实缺失或严重不足时，设计无外部 API 的合规数据获取、试采集、来源记录和人工回传。
- **数据可用性专家**：整理数据与代码清单、共享范围、仓库计划、持久标识符、FAIR 元数据和 Data Availability 声明。

## 分析与绘图

- **统计分析专家**：检查研究设计、样本和重复测量，规划或执行本地 Python/R 分析，报告效应量、置信区间、显著性和分析假设。
- **科研绘图专家**：规划、生成、适配和审核真实数据图、多面板图、算法总览、模块图、实验流程、理论框架和图形摘要。

## 写作与表达

- **论文写作专家**：基于已核验证据规划和撰写标题、摘要、引言、方法、结果、讨论、结论及投稿材料。
- **学术润色专家**：处理中英文润色、翻译、语法、清晰度、段落衔接、术语一致性和期刊风格表达。
- **AIGC 风险与作者化改写专家**：识别模板化、空泛、过度平滑和缺少作者决策的表达，围绕真实证据、判断和不确定性改写。
- **论文汇报专家**：将论文、草稿和图件组织为组会、答辩、会议或论文分享的演示结构、讲稿和 PPTX。

## 审查与投稿

- **投稿前审查专家**：从创新性、严谨性、方法统计、图件、透明度和投稿完整性进行模拟审查。
- **审稿回复专家**：逐条管理编辑与审稿意见、修改证据、回复信、修改地图和标记稿计划。
- **论文质量与期刊推荐专家**：先评估证据、创新、方法、验证、写作、图件和透明度，再按冲刺、目标和保底层级推荐期刊。

每位专家都可以独立响应对应任务，但不得替代总控执行阶段验收。
