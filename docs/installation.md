# 安装指南

## 推荐：完整安装

1. 先安装 `skills/sci-skills/`。
2. 再安装 `skills/` 下其余 13 个专家 Skill。
3. 确认 Skill 列表中显示 `SCI-Skills` 及所需专家。
4. 在新对话中发送“宝宝巴士”或“山海”，或者直接描述论文现状。

不需要 API Key、第三方接口、环境变量或账户配置。

## 按需安装

专家可以单独运行。例如只需要科研绘图时，可安装 `skills/sci-skills-scientific-figures/`；只需要论文质量评估和选刊时，可安装 `skills/sci-skills-journal-recommendation/`。

单独安装专家不会获得完整的 35 阶段控制。需要全流程推进时，应同时安装并使用总控 `sci-skills`。

## 为什么不直接把整个发布包当作一个 Skill

本目录是包含文档、宣传资源和 14 个 Skill 的产品发布包，不是单一 Skill。不同平台对多 Skill 目录的递归识别能力不同，因此 `skills/` 下的 14 个目录都直接以 `SKILL.md` 为根，可分别安装，避免因目录层级导致无法识别。

## 软件、网页和数据库操作

主线运行不要求配置外部 API。若某一步必须由用户访问网页、运行软件或操作投稿系统，总控或专家应：

1. 暂停当前论文任务并记录操作任务；
2. 生成可复制到新对话的完整陪跑 Prompt；
3. 让新对话一次指导一步；
4. 用户看不懂界面时允许发送截图；
5. 操作完成后带回文件、记录或回传卡，再恢复原论文流程。
